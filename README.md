## Project Description

This project is a multi-page personal portfolio website created during Week 1 of the IYF Weekend Academy Season 10 program. The website demonstrates foundational web development skills using semantic HTML5, accessibility principles, and GitHub Pages deployment.

The portfolio includes a homepage, about page, projects showcase, and a functional contact page with validated form inputs.

---

## Accessibility Improvements

The following accessibility enhancements were implemented:

* Added descriptive `alt` text to images
* Proper heading hierarchy (`h1 → h2 → h3`)
* Added `lang="en"` to the HTML tag
* Used semantic HTML elements
* Associated labels with form inputs
* Improved descriptive link text
